# Mergington High School - Design Standards

## Color Scheme

| Role       | Color     | Hex       |
|------------|-----------|-----------|
| Primary    | Blue      | `#1976d2` |
| Secondary  | Gray      | `#424242` |
| Background | White     | `#fafafa` |
| Text       | Dark Gray | `#212121` |
| Accent     | Light Blue| `#bbdefb` |

## Typography

- **Font Family:** Roboto (Google Fonts)
- Headings: Roboto, 500 weight
- Body: Roboto, 400 weight

## Design Principles

1. **Material-Inspired Design** — Use elevation (box-shadow), card-based layouts, and clear visual hierarchy.
2. **Responsive Layout** — The UI must adapt to desktop and mobile viewports.
3. **Clean, Modern Look** — Generous whitespace, consistent spacing, and minimal visual clutter.
4. **Accessible** — Sufficient color contrast and clear interactive states (hover, focus).
